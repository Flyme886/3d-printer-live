# 主播挂件素材（预渲染话术短片）

相框里那个会说话的形象，靠的就是这个目录里的短视频。
**不需要建模，也不需要实时推理**——每个话术对应一段提前生成好的短片，播放时只是换一段视频。

## 目录结构

```
assets/talking/
├── clips.json          # 清单：哪个角色、每个话术用哪些短片
├── source-baby.webp    # 原始素材（你的图）
├── source-crop.png     # 裁成 1:1 的版本，用来生成短片 / 当静态封面
├── idle-1.mp4          # 待机（呼吸/眨眼），循环播放
└── talk-1.mp4          # 说话动作，播完回到 idle
```

`clips.json` 里每个话术可以放多段，播放时随机挑一段，动作就不会每次都一样：

```json
{
  "characters": {
    "baby": {
      "name": "财源宝宝",
      "clips": {
        "idle":     ["idle-1.mp4"],
        "welcome":  ["talk-1.mp4", "talk-2.mp4"],
        "thanks":   ["talk-1.mp4"],
        "printing": ["talk-1.mp4"],
        "done":     ["talk-1.mp4"]
      }
    }
  }
}
```

话术含义：

| key | 什么时候播 |
|---|---|
| `idle` | 没说话的时候一直循环（观众看到的是"活的"，不是一张死图） |
| `welcome` | 有人进直播间 |
| `thanks` | 收到礼物 |
| `printing` | 开始给某位观众打印 |
| `done` | 打印完成出分 |

> 没有对应片段时会自动回落到 `talk`，再没有就保持当前画面——**不会黑屏、不会报错**。

## 怎么生成短片

两条路，都只需要**一张正面照**。

### A. 图生视频（做 idle 和"泛用动作"，最省事）

用可灵 / 即梦 / Runway / Vidu / Hedra 这类工具，上传 `source-crop.png`，提示词：

> 镜头完全固定不动，人物轻微呼吸起伏、缓慢眨眼、嘴角微微上扬微笑，动作幅度极小；首尾画面尽量一致，方便循环；不要改变人物长相和服装。

**关键**：镜头必须固定，人物不能走位，否则循环播放时会"跳"。

### B. 对口型 / 表情驱动（做"真的在说话"）

- **可灵「对口型」/ Hedra**：上传照片 + 一段配音，直接产出说话视频，最省心
- **LivePortrait**（开源）：单图驱动表情与头部微动，可本地跑
- **Wav2Lip / MuseTalk**（开源）：唇形同步，需要显卡，画质一般

录一段 3–5 秒的配音（比如"欢迎来到直播间，祝你今天好运满满"），让它对着这张图说话，导出就是 `talk-1.mp4`。

> 短片里的声音会被静音播放——真正的声音走浏览器的语音播报（TTS），所以**不要指望短片音频和 TTS 对得上**，只要口型节奏大致匹配就够了。

## 规格要求

| 项 | 要求 | 原因 |
|---|---|---|
| 画幅 | **1:1 正方形** | 挂件是方形圆形裁切，竖图会被压扁 |
| 分辨率 | 720×720 足够 | 挂件实际显示约 150px |
| 时长 | idle 3–6 秒（要能无缝循环）；talk 3–5 秒 | 太长会跟不上播报节奏 |
| 编码 | H.264 / mp4，`-movflags +faststart` | 浏览器兼容性最好 |
| 音频 | 直接去掉 | 声音由 TTS 出，避免双重声音 |

用附带的脚本一键归一化：

```bash
./scripts/prepare-clip.command 你的视频.mp4 idle
./scripts/prepare-clip.command 另一段.mp4 welcome 2   # 第 2 段欢迎语
```

脚本会自动裁成正方形、缩到 720、转 30fps、去掉音轨、加 faststart，输出到 `assets/talking/`。

## 换成自己的形象

1. 把照片放进来，裁成 1:1
2. 生成 idle + 若干 talk 短片
3. 改 `clips.json` 里的 `name` 和文件名
4. 刷新页面（`index.html` 里 `talking.bindVideo(..., {charId:'baby'})` 的 `charId` 要和 `clips.json` 里的角色 key 一致）

页面右下角控制区有「主播挂件：开/关」，状态会本地记住。

## 内置的两段素材说明

`idle-1.mp4` 和 `talk-1.mp4` 是**用 ffmpeg 从你的照片合成的占位片段**（轻微推近/点头），
用来验证整条链路能跑通，**不是真的张嘴说话**。
要真正的口型，请按上面 A/B 两种方式生成后覆盖同名文件。
