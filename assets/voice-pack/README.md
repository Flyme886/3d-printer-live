# 爷爷奶奶语音包 v1

- 24 条中文固定语音，覆盖开场、进场、礼物、互动、打印、收尾。
- `wav/`：44.1kHz 单声道 WAV 母版；`mp3/`：160kbps MP3。
- 统一响度约 -16 LUFS，单条 3.8–7.3 秒，总长约 2 分 13 秒。
- `manifest.json`：编号、分类、文案、时长、选中 seed、ASR 回查文本、评分。
- `试听合集.mp3`：按分类顺序连续试听，分类之间有稍长停顿。

## 命名

- `greet_01..04`：开场欢迎
- `enter_01..04`：新观众进场
- `gift_01..04`：礼物感谢
- `interact_01..04`：关注、点赞、评论
- `print_01..04`：打印开始、过程、完成
- `close_01..04`：收尾祝福

## 使用

直接播放 `mp3/` 或 `wav/` 中对应编号。动态昵称、具体礼物名不在本包内预生成，继续走现有 `GiftSpeech` 动态模板或在线 TTS。

## 生成说明

GPT-SoVITS v2Pro，CPU 推理，参考音未随仓库上传，`cut1`，语速 1.05。每条生成 2–3 个 take，按 ASR 文本相似度选最完整的一条；MPS 在本机会产生宽带噪声，未使用。
